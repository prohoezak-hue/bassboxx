# Validation record

Cloud machine: Debian 13, x86-64, GCC 14.2, CMake 4.4.4, JUCE 8.0.6 (pinned commit in CMakeLists.txt).

## Verified in the cloud

- Release compilation of the full JUCE VST3 instrument and standalone application on Linux.
- VST3 module manifest generated by JUCE's helper, identifying BASSBOXX as an Instrument/Synth.
- CTest: engine and JUCE processor test suites pass (2/2 suites; each contains multiple assertions).
- Engine suite: silence before notes, nonzero audio after notes, finite bounded samples, release to silence, sustain pedal hold/release, 100 factory patches with voice stealing at 44.1/48/96 kHz, panic, Bass Boost energy increase, and measured oscillator/pitch-bend frequencies.
- Processor suite: sample-position MIDI start, finite stereo audio, 100 program selections, state save/restore of parameters/program, MIDI all-sound-off, plus construction and layout bounds of all 21 synthesis knobs.
- Offscreen rendering of the actual JUCE editor to PNG. This caught and corrected an initial knob layout issue. No physical display or audio device was exercised.
- Eight-second mono PCM WAV generated by the real DSP engine, using factory patch 008 and a programmed bass sequence. This demonstrates rendering, not listening approval.
- Separate engine-only CMake configuration builds and tests without JUCE.
- Reusable cloud installation/refresh script completed successfully, including another build and test run; existing build products were reused.
- Mac build helper passes Bash syntax checking.

## Requires macOS / MPC

The cloud build produces Linux binaries, not macOS binaries. The macOS GitHub Actions workflow is configured to build a universal arm64/x86_64 VST3 and standalone app and run the same tests; its result has not been observed here. Native Mac compilation, ad-hoc signing, actual editor interaction/file dialogs, real-time audio/MIDI hardware, MPC scanning, automation and session recall, host performance and subjective listening remain to be verified using the README steps.

No Apple Developer signing/notarization or commercial JUCE license is included. This is an initial working development instrument, not a certified MPC release or an auditioned commercial preset library.

Optional checks not run: external VST3/pluginval validation, sanitizer/profiling suites, other DAWs, Windows builds, automated GUI interaction. No tests were disabled to obtain the passing result.
