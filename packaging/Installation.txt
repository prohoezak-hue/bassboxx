The Funk Box by ProHoeZak — macOS VST3 instrument

Requires macOS 11 or newer, Apple Silicon or Intel, and a desktop host supporting
VST3 instruments. MPC hardware standalone mode cannot load this plugin.

INSTALL
1. Quit MPC and other audio hosts.
2. Open The Funk Box.pkg and follow the installer. Administrator authorization
   is required to install for all users in /Library/Audio/Plug-Ins/VST3/.
3. Open MPC, scan that VST3 folder, and select The Funk Box.

UPGRADING FROM BASSBOXX
Back up existing MPC projects and custom patches before upgrading. This release
retains the previous plugin identifiers and .bassboxx patch format. Move an old
BASSBOXX.vst3 out of both your user and system VST3 folders before scanning the
new version; duplicate plugin identifiers can confuse hosts. Keep that old bundle
as a backup until you have verified your saved projects with The Funk Box.
The installer does not delete older BASSBOXX bundles or your presets/projects.

DEVELOPMENT PACKAGES
The Funk Box-development.pkg is unsigned and is for testing, not customer sales.
If macOS blocks it, use a signed and notarized customer package. Do not disable
system security protections.

SUPPORT
If silent, check audio-device settings, MIDI routing and track monitoring.
Save/load custom patches using the editor buttons; MPC projects also store state.
