BASSBOXX by ProHoeZak — local macOS VST3 development installation

FREE LOCAL-BUILD INSTALLATION (no paid Apple membership)
1. Quit MPC. Extract the entire ZIP and keep all files together.
2. Double-click "Build BASSBOXX on this Mac.command".
   If it opens Apple's free Command Line Tools installer, finish that setup,
   then double-click the builder again. No code editing or Homebrew is needed.
3. Allow several minutes and several GB of disk space. Wait for:
   "PASS: locally compiled, tested, installed and loaded".
   The builder verifies its payload and the Apple assessment of the CMake tool,
   compiles the original universal instrument, runs all four project tests,
   backs up an existing plugin, and checks the newly installed VST3 through a host.
4. Restart MPC 3.10 and enable/rescan your user VST3 folder:
   ~/Library/Audio/Plug-Ins/VST3/
   If BASSBOXX was previously failed, use MPC's rescan/retry controls. Menu names
   vary. Do not delete MPC settings or projects.
5. Add a plugin track, select BASSBOXX, enable MIDI monitoring, choose your audio
   device and play at low volume. Test saving/reopening your MPC project too.

If macOS blocks the helper or locally compiled plugin, STOP and retain its exact
message. Do not remove quarantine or change security policy. Finder launching
of the helper and MPC scanning on your specific Mac remain unverified.

WHAT THIS DOES AND DOES NOT SOLVE
The included precompiled VST3 is ad-hoc signed, not Developer ID signed/notarized.
A valid codesign result proves integrity, not Apple's approval for downloaded
software. With quarantine present, spctl can correctly reject this binary.
"Install BASSBOXX.command" refuses a quarantined/rejected bundle before replacing
an older installation. Copying it manually or re-signing it is not a trust fix.

The free route compiles NEW code locally from the original source and signs only
that new output. It does not make the download notarized. spctl may still reject
ad-hoc local code as a distribution candidate. The builder checks actual local
VST3 loading without changing Apple's policy. It never removes quarantine,
disables Gatekeeper/SIP or adds trust exceptions. A managed Mac may still refuse
local development code. Public Developer ID distribution requires the appropriate
paid Apple membership and credentials; a free account cannot supply that.

An older installation is backed up under:
~/Library/Application Support/BASSBOXX/Backups/
Builds and logs are retained under:
~/Library/Application Support/BASSBOXX/Local Builds/
The builder prints the exact Build.log path. It does not send logs anywhere.
