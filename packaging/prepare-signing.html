The Funk Box Signing File Helper

Open this downloaded HTML file on your Mac. Choose your exported FunkBox-Application.p12. This page converts it locally into the text GitHub needs. It never uploads your file and does not ask for its password.

In GitHub repository Settings → Secrets and variables → Actions, edit MAC_APPLICATION_P12_BASE64 and paste the copied text. Also update MAC_APPLICATION_P12_PASSWORD with the password you chose when exporting this file.

Then repeat using FunkBox-Installer.p12, updating MAC_INSTALLER_P12_BASE64 and MAC_INSTALLER_P12_PASSWORD.

Keep the converted text private, just like the original certificate file. Close this page when finished. File-format screening here does not verify the export password or certificate validity.
